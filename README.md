## 📦 安装

1. 将 `astrbot_plugin_soulsync/` 目录复制到 AstrBot 的 `data/plugins/` 下
2. 重启 AstrBot，或 WebUI 插件管理页点「重载插件」
3. 在插件配置页按需调整参数

纯 Python 实现，无强制依赖：图片输出需 `Pillow`、节假日调休需 `chinese-calendar`、农历精确换算需 `lunarcalendar`，未安装自动降级。

## 🔄 更新流程

```
每条消息进入 on_llm_request 钩子
  │
  ├─ ① 关键词分析（每轮必做，轻量）
  │    ├─ 有命中 → 按关键词强度计算好感变化
  │    └─ 无命中 → 微弱正向变化（好感 +0.21 × fav_growth_rate）
  │
  ├─ ② 惩罚奖励分析
  │    ├─ 行为势头检测 → 连续正面/负面行为递增奖惩（复用关键词引擎词表）
  │    ├─ 特殊事件检测 → 冷落/回归/背叛/道歉/里程碑
  │    └─ 结果按权重融合到情感变化
  │
  ├─ ③ 智能更新决策 → 是否需要调用辅助 LLM？
  │    └─ 触发条件：情绪词阈值 / 时间超时 / 计数器 / LLM标记
  │
  ├─ ④ 辅助 LLM 深度分析（条件触发，带超时保护 + 熔断）
  │    ├─ 成功 → LLM 结果与关键词结果按权重融合，生成态度/关系描述（合并进关系角色人设）
  │    └─ 失败 → 降级为纯关键词分析，不阻断流程
  │
  ├─ ⑤ 应用变更 → 更新好感 → 亲密度自动派生 → 8维情感 → 复合评分 → 阶段
  │
  └─ ⑥ 注入 LLM 请求：时间感知块(prompt前缀) + 关系角色人设(system) + 情感上下文 + 惩罚奖励提示
```

## 🎂 纪念日与节日系统

内置农历换算（1900-2100 权威数据表），自动识别**认识里程碑**（7/30/50/100/200/365/500/1000/1500/2000/3000 天）、认识周年、用户生日与 27+ 传统节日（春节/端午/七夕/中秋/除夕等）。

- 节日当天自动获得好感/亲密度奖励（每日每用户去重），并在「感知信息块」注入特别日子提示，让 AI 自然呼应氛围
- 用户侧 `/纪念日`、`/节日列表` 查看倒计时，WebUI 可视化编辑

## ⏰ 时间感知（仿 LLMPerception 实现）

每次 LLM 请求在 prompt 前缀注入一行感知信息：

```
[发送时间: 2026-09-25 14:30:00 | 周五, 下午 | 法定节假日(中秋节) | 节日: 中秋节 | 农历丙午年(马年)八月十五 | 特别日子: 中秋]
```

- 时间：发送时间 + 星期 + 时段（上午/中午/下午/晚上/深夜）
- 节假日：安装 `chinese-calendar` 后支持法定节假日与调休判断，未安装降级为周末/工作日判断
- 农历：安装 `lunarcalendar` 后精确换算（含闰月），未安装使用内置数据表（1900-2100）
- 可分别用 `enable_time_perception` / `enable_holiday_perception` / `enable_lunar_perception` 开关

## 📈 情感数据趋势

每次对话后自动记录当日好感/亲密度快照，落盘保存最近 N 天（默认 30）。

- WebUI 用户档案页内置近 7 日趋势条；数据按 `stats_history_days` 自动清理，防止膨胀

## 🎭 关系角色系统

系统内置 **39 个关系角色**（世仇/仇人/对手/厌恶/反感/冷漠路人/陌生人/笔友/网友/同桌/聊友/粉丝/室友/好友/球友/损友/老乡/死党/闺蜜/战友/挚友/知己/哥哥/姐姐/弟弟/妹妹/奶奶/爷爷/师父/叔叔/阿姨/表亲/青梅竹马/追求者/心动对象/恋人/异地恋/白月光/灵魂伴侣），解锁只能使用系统角色，不支持自定义创建。

**三种机制并存：**

| 机制 | 说明 |
|------|------|
| 🤖 聊天内容自动判定 | 根据自定义态度/关系文本 + 最近聊天消息的关键词自动匹配角色（长词加权，避免单字误判），未命中按画像推荐 |
| 🔓 用户解锁 + 一次性切换 | 满足条件可 `/解锁关系`（解锁不锁定）；`/切换关系` **切换即锁定，关系不可逆** |
| 🛠️ 管理员调整 | `/设置关系角色 <ID> <角色>` 或 WebUI 强制调整，绕过锁定与解锁条件，调整后解除锁定 |

- 每个角色有解锁条件：好感、亲密、互动次数需同时满足；负好感按深浅自动定级（世仇→仇人→对手→厌恶→反感→冷漠），与阶段负标签同源分段
- **自定义态度/关系合并**：`/设置态度`、`/设置关系`、AI 自动生成的态度/关系描述统一存储，随当前角色人设合并注入 LLM（`<stage_role>`）、自画像、状态显示与内容判定
- AI 按当前关系角色人设说话；persona 简洁（单句），负角色不含软弱化描写
- WebUI「关系角色」弹窗可查看每个用户的解锁状态、锁定标记并直接设置

## 🖨️ 图片输出

`/好感度`、`/我的画像`、`/好感排行`、`/负好感排行`、`/纪念日`、`/趋势`、`/关系阶段`、`/关系角色`、`/缓存统计`、`/查看好感`、`/调试记忆` 等信息命令均可渲染为图片卡片（Pillow 绘制，含双线趋势图）。

- **三级开关**：总开关 `enable_image_output` → 全局开关（`/全局图片模式` 或 `image_output_global`）→ 用户级开关（`/图片模式` / `image_output_default`）
- 自动探测中文字体（微软雅黑/宋体/思源黑体等），emoji 自动剔除避免缺字；未安装 Pillow 时自动降级为纯文本
- 图片文件自动保留最近 30 张，防止磁盘膨胀

## 🎯 惩罚奖励机制

## ⚙️ 配置说明

所有配置均可在 AstrBot WebUI 插件管理页面可视化编辑（数值类带滑块），保存后**无需重载插件，下次对话自动生效**。

### 功能开关

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_attitude_system` | bool | `true` | 启用态度关系系统 |
| `enable_ai_text_generation` | bool | `true` | AI 自动生成态度/关系描述 |
| `enable_secondary_llm` | bool | `true` | 启用辅助 LLM 深度情感分析 |
| `enable_smart_update` | bool | `true` | 四维智能更新 |
| `show_status_default` | bool | `false` | 默认显示情感状态行 |

### 情感参数

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `default_favorability` | float | `0.0` | 初始好感度（-100~200） |

| `fav_growth_rate` | float | `0.5` | 好感正向增长速率（v2.13 放缓 50%，负向惩罚不受影响） |

| `micro_change_intimacy` | float | `0.07` | 无关键词时每轮亲密微变化（亲密度已改为按好感度派生，此值保留兼容） |
