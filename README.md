<a id="philosophy"></a>

## 💡 核心理念

心镜 · 启明 不是"聊天机器人"，也不是"心理测试工具"。它是一面能帮你照出自己"类型轮廓"的反问镜。

**三条不可动摇的原则：**
1. **不贴标签、不给结论** — 只反问，让用户自己看见
2. **反问中自然映射图鉴维度** — 每个图鉴有专属的 2-5 个维度
3. **红线四条：不给建议、不共情、不复述、不诊断**

**输出形式：**
- 每轮：反问句（必带"？"）
- 结束：轮廓卡（维度信号 + 可能参考 + 反问收尾）

<a id="install"></a>

## 📦 安装

1. 将 `astrbot_plugin_soulsync_mirror/` 目录复制到 AstrBot 的 `data/plugins/` 下
2. 重启 AstrBot，或 WebUI 插件管理页点「重载插件」
3. 在插件配置页按需调整参数

纯 Python 实现，无强制依赖。需配置 LLM 服务以获得最佳反问体验（无 LLM 时自动降级为模板反问）。

<a id="core"></a>

## 🧬 核心机制

### 通用模式

自由聊天 → 自然产生数据 → 反问中捕捉维度信号 → 结束时生成轮廓卡。

**反问规则：**
1. 句末必带「？」
2. 禁止建议、禁止共情、禁止复述（不说「你感到」）
3. 字数 ≤ 用户输入 × 1.5
4. 用户问「怎么办」时，先给两个「有人…有人…」视角，再反问

### 图鉴模式（157 个）

进入图鉴后，反问围绕该图鉴的核心维度展开，逐轮捕捉信号，6 轮后自动输出轮廓卡。

**图鉴覆盖 5 大分类：**

| 分类 | 数量 | 示例 |
|------|------|------|
| 🧠 科学量表 | 23 | MBTI、九型、大五、HSP |
| 💞 关系情感 | 52 | 依恋类型、攻受体质、恋爱脑 |
| 🌦️ 情绪状态 | 28 | 抑郁倾向、焦虑、内耗、社恐 |
| 🌐 社交与职场 | 12 | 霍兰德、DISC、班味浓度 |
| 🎉 网络玩梗与趣味 | 42 | SBTI、动物人格、吗喽人格 |

## ⚙️ 配置说明

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_illuminate_mode` | bool | true | 是否启用启明反问模式 |
| `guide_max_rounds` | int | 6 | 图鉴模式最大反问轮数（3-12） |

| `list_max_aliases_display` | int | 3 | 列表中每个图鉴最多展示的别名数（1-5） |
| `history_max_rounds` | int | 6 | 对话历史保留轮数（2-10） |
| `session_timeout_minutes` | int | 10 | 会话超时时间（分钟） |
| `max_output_length_ratio` | float | 1.5 | 最大输出长度比例（1.0-3.0） |
| `end_keywords` | string | 结束,再见,拜拜... | 结束词列表（逗号分隔） |

## 🙏 设计理念

心镜 · 启明 的设计灵感来自"反问镜"的概念——它不给你答案，只通过反问帮你看见自己的轮廓。

测试设计的精髓被转化：
- **固定题目** → 自由聊天，自然产生数据
- **多维度测量** → 反问中捕捉维度信号（E/I、S/N、T/F 等）
- **类型结果标签** → 不输出标签，只折叠成"可能的类型参考"（以反问收尾）
- **自我观察定位** → 明确标注"仅供自我探索，不替代诊断"
