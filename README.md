# 心旅小馆（SoulSync Bistro）

🍽️ 一个 AstrBot 插件：根据 SoulSync 检测到的聊天情绪，推荐合适的菜谱。

情绪 → 美食映射：

| 情绪 | 主题 | 示例方向 |
|------|------|----------|
| 😊 喜悦 | 庆祝餐 | 硬菜、烤焗、虾、牛排 |
| 😢 悲伤 | 治愈甜品 | 甜品、粥、汤、软糯 |
| 😠 愤怒 | 释放辣味 | 川菜、香辣、下饭 |
| 😟 焦虑 | 安神清淡 | 清淡、蒸、粥、汤 |
| 🤩 期待 | 创意尝鲜 | 日式、意式、法式、异国 |

## 功能

- **自动情绪感知**：通过 `on_llm_response` 钩子截取 SoulSync 的 LLM 回复，本地词典分析情绪（喜悦/悲伤/愤怒/焦虑/期待/平静），缓存快照 30 分钟（可配置）
- **2081 道本地菜谱**：中国菜 464 道（八大菜系/云贵少数民族/街头小吃/家常/汤粥甜/早餐主食）+ 外国菜 231 道（日韩/东南亚/印中东/欧陆/拉美/非洲等）+ 饮品 50 道 + 手写补充 1336 道，全部含详细步骤，运行时零网络
- **情绪特调**：每道菜带 mood_hint 标注，推荐保证优先当前情绪适配
- **三类场景推荐**：套餐（主菜+主食+配菜+甜品）、饮品、解馋小食，均支持群聊无前缀触发

## 指令

| 指令 | 说明 |
|------|------|
| `/吃点啥 [分类]` | 推荐一份套餐（主菜+主食+配菜+甜品），指定分类则推荐单菜（素菜/荤菜/主食/汤/甜品/凉菜） |
| `/喝点啥` | 按情绪推荐一杯饮品（奶茶/咖啡/果汁/糖水等 67 款） |
| `/解馋 [数量]` | 推荐解馋小食（小吃/甜品/炸鸡/烧烤等 300 款） |
| `/菜谱搜索 关键词` | 搜索菜谱库，与当前情绪契合的标注 ❤️此刻适配 |
| `/怎么做 菜名` | 查看详细做法步骤（含食材、视频参考） |
| `/随机推荐 [数量]` | 随机推荐 N 道，至少一道情绪特调 |
| `/心馆 状态` | 查看当前情绪快照与推荐摘要 |

群聊中不带斜杠、不 @ 机器人时，说「吃点啥/吃什么」「喝点啥/喝什么」「解馋/馋了/嘴馋」同样能触发对应推荐。

## 配置

| 配置项 | 默认 | 说明 |
|--------|------|------|
| enable_mood_link | true | 情绪联动开关 |
| mood_ttl_minutes | 30 | 情绪快照有效期（1-1440） |
| max_search_results | 8 | 搜索结果条数上限（1-20） |

情绪 → 菜谱映射可在 `mood_mapping.json` 中自定义（关键词/标签/回复语）。

## 数据与许可

- 菜谱数据来源：[YunYouJun/cook](https://github.com/YunYouJun/cook)（MIT，`app/data/recipe.csv`，含视频 BV 号）与 [DingJunyao/HowToCook_json](https://github.com/DingJunyao/HowToCook_json)（CC BY-NC-SA 4.0，火候/时间/用量详解），另含手写中国菜 464 道、外国菜 231 道与饮品 50 道
- 合并去重后共 2081 道，每道含：名称、分类、食材、步骤、标签、难度、工具、辣度、是否素菜、情绪提示

## 开发

```bash
# 回归测试（不依赖 AstrBot，仅需 Python 3.8+）
python -m pytest tests -v
```

`tools/` 内含数据构建脚本：`build_recipes.py`（CSV→JSON）、`merge_steps.py`（子代理步骤合并）、`merge_howtocook.py`（HowToCook 合并）、`validate.py`（数据校验）。
