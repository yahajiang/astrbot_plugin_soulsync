# 心镜 (SoulMirror) - 镜像反射对话插件

> 一面有回应的镜子。不给建议、不共情、不分析，只把你此刻说出来的话，经过镜面折射后，以更清晰的形式返还给你。

<a id="philosophy"></a>

## 💡 核心理念

心镜不是"有记忆的AI"，也不是"聊天机器人"。它是一面有回应的镜子。

**三条不可动摇的原则：**
1. 主角永远是用户本人，AI不充当对话中的任何角色
2. 每一次对话都是即兴的、当下的，不依赖任何历史数据
3. 镜子的数据永远来自用户正在打字的那个瞬间

**镜子的边界：**
心镜不擅长回应生死和极端危机。当用户释放出这类信号时，镜子会主动放下，引导用户去找到真正能帮助他们的人。

<a id="install"></a>

## 📦 安装

1. 将 `astrbot_plugin_soulmirror/` 目录复制到 AstrBot 的 `data/plugins/` 下
2. 重启 AstrBot，或 WebUI 插件管理页点「重载插件」
3. 在插件配置页按需调整参数

纯 Python 实现，无强制依赖。

## 🧬 核心机制

### 三层反射逻辑

| 层级 | 类型 | 说明 | 示例 |
|------|------|------|------|
| 第一层 | 复述式反射 | 将用户的「我」转换为「你」，原样复述 | 用户："我好累" → 镜子："你说你好累。" |
| 第二层 | 归因式反射 | 提取因果关系，转化为开放式假设 | 用户："我好累" → 镜子："这种累，是身体在抗议，还是心里在抗拒？" |
| 第三层 | 追问式反射 | 将问题反转抛回给用户 | 用户："我好累" → 镜子："如果给这个累取一个名字，它会叫什么？" |

### 四种镜面类型

| 类型 | 说明 | 使用场景 |
|------|------|----------|
| 平面镜 | 原样反射，1:1还原 | 用户表达清晰情绪明确时 |
| 凹面镜 | 聚焦，收束焦点 | 用户表达模糊欲言又止时 |
| 凸面镜 | 展开，拆分多层情绪 | 用户一句话包含多层情绪时 |
| 棱镜 | 折射，呈现矛盾 | 用户的话里隐含矛盾时 |

### 五级锐度系统

| 等级 | 名称 | 说明 |
|------|------|------|
| 1 | 水面 | 只做最轻的语态转换 |
| 2 | 静镜 | 复述后加轻柔开放式问题（默认） |
| 3 | 聚焦 | 把模糊情绪拆成具体维度给二选一 |
| 4 | 锐面 | 直接捕捉矛盾或盲区 |
| 5 | 深渊 | 字数最少最短句子里装最重的东西 |

### 六问破冰握手

破冰分为两个阶段：固定三问 + 随机三问，共六轮对话。

**固定三问：**
1. 称呼："你叫什么名字？"
2. 一句话："你今天来，心里有没有一句话一直转着？"
3. 三个词："如果让你用三个词形容自己最近的状态？"

**随机三问：**
- 暖区问题（低压力）：今天吃了什么？最近听的歌？想出现在哪里？
- 冷区问题（中等压力）：今天打几分？最想做什么？有没有在拖的事？

### 动态修正机制

- **称呼修正**：用户说「叫我XX」→ 镜子确认「好，之后叫你XX」
- **内容修正**：
  - 强修正（改变情绪方向）：自然语言同时提及新旧两个词
  - 小修正（同义强化）：静默不标注
  - 模糊修正：新词反射末尾加轻追问

### 安全红线

当用户输入中出现自伤、自杀倾向的直接表述时，镜子立即退出镜像模式：

> 镜子暂时放下了。你现在说的这些，需要被一个真实的人听见。
> 请拨打24小时心理援助热线：400-161-9995（希望24热线）。

### 防干扰协议

**三层隔离防护：**

1. **指令隔离**：心镜的系统指令独立于宿主指令，不共享上下文
2. **行为锚定**：5条核心规则写死不可修改
   - 不引入外部信息
   - 不表达个人观点
   - 不主动展开（回复≤用户输入1.5倍）
   - 不打破第四面墙
   - 不承接新角色
3. **输入过滤**：检测并隔离角色切换、元指令注入、人格模拟请求

<a id="config"></a>

## ⚙️ 配置说明

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_sharpness_auto` | bool | true | 启用自动调锐 |
| `enable_repeat_detection` | bool | true | 启用重复词检测 |
| `enable_conflict_detection` | bool | true | 启用矛盾检测 |
| `enable_quote_storage` | bool | true | 启用金句存储 |
| `silent_mode` | bool | false | 静默模式 |
| `max_quote_count` | int | 10 | 最大金句数量 |
| `session_timeout_minutes` | int | 10 | 会话超时时间（分钟） |
| `max_dialogue_history` | int | 20 | 最大对话历史轮数 |
| `sharpness_default` | int | 2 | 默认锐度等级 |
| `sharpness_max_change_per_turn` | int | 1 | 单轮最大锐度变化 |
| `sharpness_consecutive_limit` | int | 3 | 连续升锐限制 |
| `repeat_threshold` | int | 3 | 重复词触发阈值 |
| `repeat_window` | int | 5 | 重复词检测窗口 |
| `max_output_length_ratio` | float | 1.5 | 最大输出长度比例 |
| `icebreaker_timeout_minutes` | int | 10 | 破冰超时时间（分钟） |

## 🙏 设计理念

心镜的设计灵感来自"镜子"的概念——它不给你答案，只帮你听清自己在说什么。

用户说得越真实，镜子就越清晰。用户说得模糊，镜子就帮他把模糊变成可选择的维度。

它的数据，永远来自用户正在打字的那个瞬间。
