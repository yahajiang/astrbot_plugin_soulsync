<a id="philosophy"></a>

## 💡 核心理念

心镜 · 启明 不是"聊天机器人"，也不是"心理测试工具"。它是一面能帮你照出自己"类型轮廓"的反问镜。

**三条不可动摇的原则：**
1. **不贴标签、不给结论** — 只反问，让用户自己看见
2. **反问中自然映射图鉴维度** — 每个图鉴有专属的 2-5 个维度
3. **红线四条：不给建议、不共情、不复述、不诊断**

**输出形式：**
- 每轮：反问句（必带"？"）
- 结束：轮廓卡（维度信号 + 可能参考 + 反问收尾）

<a id="install"></a>

## 📦 安装

1. 将 `astrbot_plugin_soulsync_mirror/` 目录复制到 AstrBot 的 `data/plugins/` 下
2. 重启 AstrBot，或 WebUI 插件管理页点「重载插件」
3. 在插件配置页按需调整参数

纯 Python 实现，无强制依赖。需配置 LLM 服务以获得最佳反问体验（无 LLM 时自动降级为模板反问）。

| 命令 | 说明 | 示例 |

## 🧬 核心机制

### 图鉴探索（核心流程）

`/心镜` → 图鉴列表 → 选择图鉴 → 对话式探索 → 轮廓卡

**探索方式：**
- 像朋友聊天一样，从用户说的话里找到有意思的点，自然追问
- 一次只聊一个角度，聊透了再换下一个
- 用具体场景、假设、例子来问
- 探索中禁止切换图鉴，防止跳出

**图鉴覆盖 5 大分类：**

| 分类 | 数量 | 示例 |
|------|------|------|
| 🧠 科学量表 | 23 | MBTI、九型、大五、HSP |
| 💞 关系情感 | 52 | 依恋类型、攻受体质、恋爱脑 |
| 🌦️ 情绪状态 | 28 | 抑郁倾向、焦虑、内耗、社恐 |
| 🌐 社交与职场 | 12 | 霍兰德、DISC、班味浓度 |
| 🎉 网络玩梗与趣味 | 42 | SBTI、动物人格、吗喽人格 |

<a id="config"></a>

## ⚙️ 配置说明

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `guide_max_rounds` | int | 6 | 图鉴模式最大反问轮数 |
| `guide_auto_exit` | bool | true | 达到最大轮数后自动退出 |
| `enable_profile_on_end` | bool | true | 结束时生成轮廓卡 |
| `enable_guide_list` | bool | true | 启用 /心镜 列表 命令 |
| `list_max_aliases_display` | int | 3 | 列表中每个图鉴最多展示的别名数（1-5） |
| `history_max_rounds` | int | 6 | 对话历史保留轮数 |
| `session_timeout_minutes` | int | 30 | 会话超时时间（分钟） |
| `max_output_length_ratio` | float | 0 | 最大输出长度比例（0=不限制） |
| `end_keywords` | string | 结束,再见,拜拜... | 结束词列表（逗号分隔） |
| `safe_mode` | bool | true | 是否启用安全红线 |
| `llm_provider` | string | 空 | LLM 服务商（留空使用默认） |
| `llm_timeout` | int | 30 | LLM 调用超时时间（秒） |
| `profile_max_length` | int | 0 | 轮廓卡最大字数（0=不限制） |

## 🙏 设计理念

心镜 · 启明 的设计灵感来自"反问镜"的概念——它不给你答案，只通过反问帮你看见自己的轮廓。

- **图鉴即入口** — 直接进入图鉴探索，无通用模式
- **对话式探索** — 像朋友聊天一样追问，不像问卷调查
- **维度信号捕捉** — 从对话中自然捕捉维度信号，不点破
- **轮廓卡输出** — 结束时生成结构化轮廓卡，供自我参考
