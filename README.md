# 心旅小馆（SoulSync Bistro）

🍽️ 一个 AstrBot 插件：根据 SoulSync 检测到的聊天情绪，推荐合适的菜谱。

情绪 → 美食映射：

| 情绪 | 主题 | 示例方向 |
|------|------|----------|
| 😊 喜悦 | 庆祝餐 | 硬菜、烤焗、虾、牛排 |
| 😢 悲伤 | 治愈甜品 | 甜品、粥、汤、软糯 |
| 😠 愤怒 | 释放辣味 | 川菜、香辣、下饭 |
| 😟 焦虑 | 安神清淡 | 清淡、蒸、粥、汤 |
| 🤩 期待 | 创意尝鲜 | 日式、意式、法式、异国 |

## 功能

- **自动情绪感知**：通过 `on_llm_response` 钩子截取 SoulSync 的 LLM 回复，本地词典分析情绪（喜悦/悲伤/愤怒/焦虑/期待/平静），缓存快照 30 分钟（可配置）
- **4000 道本地菜谱**：中国菜 464 道（八大菜系/云贵少数民族/街头小吃/家常/汤粥甜/早餐主食）+ 外国菜 231 道（日韩/东南亚/印中东/欧陆/拉美/非洲等）+ 饮品 50 道 + 手写补充 3255 道，全部含详细步骤，运行时零网络
- **情绪特调**：每道菜带 mood_hint 标注，推荐保证优先当前情绪适配
- **三类场景推荐**：套餐（主菜+主食+配菜+甜品）、饮品、解馋小食，均支持群聊无前缀触发
- **反馈闭环（v1.4）**：推荐记录 3 天去重不重复推同菜；`/好吃` `/不好吃` 反馈计入个人喜好分（赞 +0.1/次、踩 −0.3/次，随天数衰减），下次推荐加权微调
- **口味档案（v1.5）**：每用户设置忌口与偏好——忌口（不吃香菜/不吃内脏/不吃海鲜/不吃辣/不吃葱姜蒜/素食）硬排除，偏好（喜欢面食/米饭/粥/烧烤/甜品/清淡）+0.15/项加权；基于食材+名称匹配（鱼香肉丝不会被海鲜忌口误伤），数据存 `data/user_profiles.json`（不入库）
- **时间感知（v1.7）**：节假日（元旦/春节/元宵/端午/中秋/冬至）推荐应景菜（候选落空则只祝福）；季节加权（春笋/绿豆/羊肉等时令食材命中 +0.1~0.2）；晚餐时段提示快手菜；`/今天` 查看节日/季节/时段
- **食材反查（v1.9）**：`/家里有 鸡蛋,番茄` 按手头食材反查可做菜——覆盖度排序、别名匹配（西红柿↔番茄、五花肉↔猪肉等 80+）、调味料豁免（盐/糖/油/葱姜蒜不计入缺失）、缺项标注、情绪适配标 ❤️

## 指令

| 指令 | 说明 |
|------|------|
| `/吃点啥 [分类]` | 推荐一份套餐（主菜+主食+配菜+甜品），指定分类则推荐单菜（素菜/荤菜/主食/汤/甜品/凉菜） |
| `/喝点啥` | 按情绪推荐一杯饮品（奶茶/咖啡/果汁/糖水等 67 款） |
| `/解馋 [数量]` | 推荐解馋小食（小吃/甜品/炸鸡/烧烤等 300 款） |
| `/菜谱搜索 关键词` | 搜索菜谱库，与当前情绪契合的标注 ❤️此刻适配 |
| `/怎么做 菜名` | 查看详细做法步骤（含食材、视频参考） |
| `/随机推荐 [数量]` | 随机推荐 N 道，至少一道情绪特调 |
| `/好吃 [菜名]` | 标记喜欢（不带菜名标记上一道推荐的菜） |
| `/不好吃 [菜名]` | 标记不喜欢 |
| `/我的口味` | 查看个人反馈统计（最爱/踩雷/最近推荐） |
| `/口味设置 标签` | 设置口味档案，逗号分隔多个标签（忌口/偏好，如：`/口味设置 不吃香菜,喜欢面食`） |
| `/口味查看` | 查看当前口味档案 |
| `/口味重置` | 清空口味档案 |
| `/今天` | 查看今日节日/季节/时段建议 |
| `/家里有 食材` | 按手头食材反查可做的菜（逗号分隔，如：`/家里有 鸡蛋,番茄`） |
| `/心馆 状态` | 查看当前情绪快照与推荐摘要 |

群聊中不带斜杠、不 @ 机器人时，说「吃点啥/吃什么」「喝点啥/喝什么」「解馋/馋了/嘴馋」同样能触发对应推荐。

## 配置

| 配置项 | 默认 | 说明 |
|--------|------|------|
| enable_mood_link | true | 情绪联动开关 |
| mood_ttl_minutes | 30 | 情绪快照有效期（1-1440） |
| max_search_results | 8 | 搜索结果条数上限（1-20） |

情绪 → 菜谱映射可在 `mood_mapping.json` 中自定义（关键词/标签/回复语）。

## 数据与许可

- 菜谱数据来源：[YunYouJun/cook](https://github.com/YunYouJun/cook)（MIT，`app/data/recipe.csv`，含视频 BV 号）与 [DingJunyao/HowToCook_json](https://github.com/DingJunyao/HowToCook_json)（CC BY-NC-SA 4.0，火候/时间/用量详解），另含手写中国菜 464 道、外国菜 231 道与饮品 50 道
- 合并去重后共 4000 道，每道含：名称、分类、食材、步骤、标签、难度、工具、辣度、是否素菜、情绪提示
